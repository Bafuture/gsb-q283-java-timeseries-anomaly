## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们的监控指标需要自动标出异常点，但阈值写死会误报，简单移动平均又会漏掉突增。请从零实现一个时间序列异常点检测组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持建立基线：用滑动窗口统计均值与标准差，窗口大小可配置；2) 支持检测突增与突降：偏离基线若干倍标准差视为异常，同时要考虑周期性（例如工作日与周末不同）；3) 支持季节性处理：按小时或按星期建立多条基线，查询时选择对应基线，需说明冷启动时的降级策略；4) 支持误报控制：连续多次偏离才算异常，或需要相邻点共同印证，规则可配置；5) 支持检测评估：用带标注的合成序列统计准确率、漏报率与误报率，并与固定阈值方案对比；6) 支持异常合并：相邻异常点合并为一个异常区间，便于告警；7) 提供统计：检测点数、异常点数、误报数与合并后区间数；8) 测试覆盖基线计算、突增突降、季节性基线、误报控制、评估对比与区间合并；`mvn -q verify` 一条命令跑通。
